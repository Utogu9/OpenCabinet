# Removable discs

Open a supported 3D case and click its disc, or choose **Remove disc** from
the case's context menu. The disc lifts out, moves right, and lowers back to
the box's height; reinsertion follows that path in reverse. The case slides left within
the same viewer. The inlay remains visible in the empty case.

Click either object to direct dragging, wheel zoom and the existing rotation
controls to it. The small **Box** and **Disc** buttons also select an object.
Disc dragging uses its own projected center. Rotating it keeps the camera
distance steady; resizing the viewer still adjusts the framing.
**Flip disc** shows the opposite side; **Put disc back** animates reinsertion.
The same controls work in the sidebar, fullscreen and couch mode. The controller's
right stick and triggers act on the selected object in couch mode.

The **Disc underside** option in the game's or console's 3D case settings offers
silver, black, blue and gold finishes. Automatic uses a shared silver DVD finish
with concentric rings and view-dependent diffraction colors. PS2 CD releases can be set to blue individually; a PS2
game is not assumed to be a CD just because it belongs to that platform.

Extraction uses the actual model's surfaces, including the smaller GameCube disc
and PSP's UMD housing. Both objects share one scene, renderer, geometry and
artwork. Removal changes presentation only and is reset when changing games;
it does not change files, disc associations or play statistics. Cartridge and
cardboard cases do not expose optical disc actions.

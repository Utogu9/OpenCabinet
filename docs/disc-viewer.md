# Removable discs

Open a supported 3D case and click its disc, or choose **Remove disc** from
the case's context menu. The disc lifts out, moves right, and lowers back to
the box's height; reinsertion follows that path in reverse. The case slides left within
the same viewer. The inlay remains visible in the empty case.

Click either object to direct dragging, wheel zoom and the existing rotation
controls to it. **Examine box** in the context menu returns focus to the case.
Disc dragging uses its own projected center. Rotating it keeps the camera
distance steady; resizing the viewer still adjusts the framing.
The main front/back control flips the selected disc; **Put disc back** animates reinsertion.
The same controls work in the sidebar, fullscreen and couch mode. The controller's
right stick and triggers act on the selected object in couch mode.

The **Disc underside** option in the game's or console's 3D case settings offers
silver, black, blue and gold finishes, independently of the printed label.
Automatic uses black for PlayStation CDs and silver for other supported optical
formats: PS2 DVD, PS3/PS4/PS5, Xbox/Xbox 360, Wii/Wii U/GameCube, PSP, Dreamcast,
Sega CD and Saturn. Platform settings can override that default; a game or regional
override takes priority over the inherited platform setting.
PS2 CD releases can be set to blue individually. A filename or compressed image
size does not reliably identify a PS2 CD, so PS2 stays silver in automatic mode.
Gold is available for specific editions, rather than inferred from a console.
Silver, blue and gold retain concentric rings and view-dependent diffraction.
Black uses a neutral, dark substrate without additive rainbow colors and with
very faint rings; its ordinary light reflections remain subtle.

Sony's [official PS2 manual](https://www.sony.co.in/microsite/playstation/product/ps2/ps2.pdf)
lists silver PS2 DVD-ROMs, blue PS2 CD-ROMs and black PlayStation CD-ROMs.

Extraction uses the actual model's surfaces, including the smaller GameCube disc
and PSP's UMD housing. Both objects share one scene, renderer, geometry and
artwork. Removal changes presentation only and is reset when changing games;
it does not change files, disc associations or play statistics. Cartridge and
cardboard cases do not expose optical disc actions.
